# ZX-TV

موقع أفلام (ثابت — HTML/CSS/JS بدون أي أدوات بناء) يشتغل مباشرة على GitHub Pages.

## الصفحات
- `index.html` — الرئيسية: فلم مختار متحرك، صفوف حسب التصنيف، بحث حي، تصنيفات، ترتيب
- `movie.html?id=...` — تفاصيل الفلم: التريلر، تقييمك بالنجوم، «شفته»، مشاركة، أفلام تشبهه
- `mylist.html` — قائمتي (أريد أشوفها / شفتها)، محفوظة بالمتصفح (localStorage)

## هيكل المشروع
```
config.js        الإعدادات (مفتاح TMDB اختياري)
data/genres.js   التصنيفات
data/movies.js   الكتالوج المحلي (بيانات تجريبية)
js/api.js        طبقة البيانات (محلي أو TMDB بنفس الواجهة)
js/store.js      التخزين المحلي
js/ui.js         الهيدر، البطاقات، الصفوف، نافذة التريلر
js/home.js · movie.js · mylist.js
css/style.css
```

## إضافة فلم محلي
افتح `data/movies.js` وأضف كائناً جديداً (الحقول مشروحة بأعلى الملف). اختيارياً:
`poster` رابط صورة، `trailer` معرّف فيديو يوتيوب، `video` رابط mp4 لفلم تملك حق عرضه.

## أفلام حقيقية من TMDB (اختياري)
1. سوّي حساب مجاني بـ themoviedb.org وخذ مفتاح API (v3).
2. حطه بـ `config.js` بحقل `TMDB_KEY`.
3. الموقع يتحول تلقائياً لبيانات حقيقية: بوسترات، تريلرات، ممثلين، بحث بكل الأفلام.

> المفتاح يظهر بكود الموقع (موقع ثابت)، وهذا طبيعي لمفاتيح TMDB للقراءة فقط.

## تشغيل محلي
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000
